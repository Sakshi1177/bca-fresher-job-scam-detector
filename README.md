# BCA Fresher Job Scam Detector - 100 Jobs Analysis

## By Sakshi Pradhan - BCA Fresher - Project 4

### Why I Made This Project?

I am BCA Fresher. I applied to many jobs on LinkedIn, Indeed, Naukri. Some jobs asked for money - Rs 500, Rs 999. I got confused which is real which is scam. So I decided to collect 100 jobs data and analyze.

### What I Learned in College vs What Companies Want?

**In My College (BCA):**
- We learned C, C++ basics
- Also learned SQL and Python basics - theory, queries, loops, DBMS
- But mostly theory and small lab programs

**What Companies Want in Real Jobs (My Finding from 100 Jobs):**
- **Advanced Excel** - VLOOKUP, Pivot Table, Charts - 48% jobs (My college taught basic Excel only)
- **Advanced SQL** - Joins, Group By, Real database handling - 42% jobs (College taught simple SELECT only)
- **Python with Projects** - Pandas, Real data analysis - 29% jobs (College taught basic syntax)
- **Tableau / Power BI** - Dashboard making - 15% jobs (Not taught in college)
- **Real Projects** - They want GitHub projects, not just marks

So gap is not subject, gap is **Theory vs Practical + Projects**. College taught basics, companies want practical with projects.

### My Findings from 100 Jobs:

1. **18% Jobs are SCAM!** - They ask for money. They show high salary Rs 40000-50000 to trap freshers. Real jobs give Rs 15000-25000.

2. **Real Salary:** For BCA Fresher, Real salary is Rs 15k-25k in starting, not Rs 50k. SCAM jobs show 50k to attract.

3. **Top Skills in Demand:**
   - Excel (Advanced) - 48 jobs out of 100
   - SQL (Advanced) - 42 jobs
   - Python - 29 jobs
   - Communication - 20 jobs
   - Tableau - 10 jobs

4. **Source:** LinkedIn has less scam (5% scam), Indeed has some, WhatsApp/Facebook groups have more scam (50% scam).

### Tech Stack I Used:

- **Excel:** Collected 100 jobs manually in Excel. Made 2 charts - Pie chart Real vs Scam, Bar chart Top Skills.

- **SQL:** Wrote 6 simple queries - Count scam, Average salary, Top skills, Source wise scam.
